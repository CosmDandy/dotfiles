# Work 3 — режимы Pi

Эксперимент в ветке `work-3`, отдельно от основной рабочей копии и установленного профиля Pi.

- **Execute — режим по умолчанию.** Обсуждение и реализация остаются в одном диалоге. Pair / Autonomous определяют, когда спрашивать пользователя; Agents независимо включает помощников для исследования и ревью. Отдельной метки Execute нет, рамка нейтрально-серая.
- **Foreman — тот же диалог, другой исполнитель.** Главный агент держит цель, границы, решения и приёмку. После разрешения пишет один фоновый исполнитель в текущей рабочей копии; следующие поручения по задаче идут в его сохранённый контекст. Главный читает и смотрит diff, но не правит файлы и не запускает произвольные команды. Пока исполнитель пишет, нельзя вернуться в Execute. Для пробы не менять модели и не добавлять таймер.
- **TODO: Explore для глубокого исследования.** Сейчас оставить поведение как есть. Затем дать режиму более подробные ответы и мандат докапываться до первоисточника: рассматривать альтернативы, воспроизводить наблюдения, перепроверять выводы отдельными проверками или скриптами и явно отмечать, что доказано, а что не удалось проверить. Это не обязательная прелюдия к Execute.

Запуск пробы из этой рабочей копии, без замены глобальных расширений:

```sh
pi --name 'Work 3' --no-extensions -e tools/pi/extensions/work-mode.ts \
  -e tools/pi/extensions/solarized-status.ts -e tools/pi/extensions/sol-medium.ts
```

После запуска: `/foreman`. Команда загружает только расширения, нужные для пробы.

Проверка пробы: новый сеанс открывается без метки Execute; Explore и переключатели работают как раньше; Foreman не может писать напрямую, запускает только одного исполнителя, получает результат и продолжает его контекст. Подтвердить на изолированном профиле, не активируя Home Manager.
