# Компактные инструменты Pi

`extensions/compact-tools.ts` меняет только отображение вызовов, не их выполнение.
Строки показывают ожидание, анимацию выполняющегося инструмента и результат.
Имя инструмента остаётся жирным во время анимации и для приглушённых вызовов к `[tmp]`.

Живая карточка `subagents` в чате перечисляет агентов. Для каждого показывает модель,
reasoning, `fresh` / `fork`, токены, время и краткое превью инструмента, например
`shell · rg …`. Для фоновых запусков обновления идут по событиям `pi-subagents`.
Заголовок `subagents · …` выровнен с обычными инструментами. Время агента и итоговое
время карточки приглушены и стоят у правого края. Как только агент заканчивает,
его имя меняет цвет в заголовке и в его строке. После завершения всех агентов
остаётся одна строка с приглушённым счётчиком токенов у каждого имени и причиной
ошибки, если она есть. Клик и `Ctrl+O` не раскрывают карточку; полная история —
в `/agents` или по `↓` из пустого поля ввода.
У обычных инструментов длительность видна с 10 секунд выполнения, в том числе
у вложенных вызовов Codemode.
Ошибки инструментов, Codemode и сабагентов обозначаются одним приглушённым красным.
Отметки успешного завершения окрашены в более тёмный Solarized-зелёный.
Цвета, которые команды выводят сами, сохраняются при раскрытии.
В свёрнутом прямом Bash заданный тайм-аут виден с 10-й секунды работы. После завершения
он остаётся при расходе от 80% лимита или при срабатывании; при раскрытии виден всегда.
Пороги не влияют на выполнение и сбор статистики.
Подробности содержат аргументы и вывод; для `edit` показываются diff и число
добавленных и удалённых строк. Вывод `bash` раскрыт по умолчанию.

Свёрнутый Codemode показывает счётчики, а после 600 мс — статусы вложенных
инструментов. Ошибки и отмены остаются видимыми после завершения. Раскрытие
показывает все вызовы, скрипт и его вывод.

Для прямого и вложенного Bash сводка сохраняет операторы цепочки, заменяет
пролог короткими метками и сворачивает длинные пути и heredoc. Исходный Bash
виден при раскрытии; для вложенных вызовов в истории это зависит от того,
сохранил ли Pi полные аргументы.

Загрузить для проверки, не изменяя настройки:

```sh
pi --extension ./tools/pi/extensions/compact-tools.ts
```

`Ctrl+O` переключает вывод всех инструментов; `bash` начинается в противоположном
состоянии, поэтому переключается наоборот. В fullscreen можно нажать на отдельную
строку. В обычном режиме мышью управляет терминал. Вместо содержимого изображений
рендерер показывает их тип.

Проверка без запросов к модели:

```sh
node tools/pi/tests/compact-tools.test.mjs
```

Для Nix-версии Pi при необходимости задайте `PI_TEST_MODULES`, как в основном
`tools/pi/README.md`. Linux Home Manager подключает расширение автоматически.
