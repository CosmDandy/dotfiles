# Компактные инструменты Pi

`extensions/compact-tools.ts` меняет только отображение вызовов, не их выполнение.
Строки показывают ожидание, анимацию выполняющегося инструмента и результат.
Подробности содержат аргументы и вывод; для `edit` показываются diff и число
добавленных и удалённых строк. Вывод `bash` раскрыт по умолчанию.

Загрузить для проверки, не изменяя настройки:

```sh
pi --extension ./tools/pi/extensions/compact-tools.ts
```

`Ctrl+O` переключает вывод всех инструментов; `bash` начинается в противоположном
состоянии, поэтому переключается наоборот. В fullscreen можно нажать на отдельную строку. В обычном режиме мышью управляет терминал.
Изображения отображаются штатным механизмом Pi, когда это позволяет терминал.

Проверка без запросов к модели:

```sh
node tools/pi/tests/compact-tools.test.mjs
```

Для Nix-версии Pi при необходимости задайте `PI_TEST_MODULES`, как в основном
`tools/pi/README.md`. Для постоянного подключения расширение должно быть доступно
в `.pi/agent/extensions/`.
